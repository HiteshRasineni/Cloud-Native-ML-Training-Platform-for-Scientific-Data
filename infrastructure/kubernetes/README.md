# Kubernetes deployment

This directory is a Kustomize deployment for the complete platform. Apply it with:

```text
kubectl apply -k infrastructure/kubernetes/
```

The scheduler uses `EXECUTOR_BACKEND=kubernetes` and its ServiceAccount creates an indexed `batch/v1 Job` for each experiment. `resources.workers` controls both `parallelism` and `completions`. Each Pod mounts a per-job ConfigMap containing the experiment JSON and selects its worker ID from the indexed completion label. The executor maps Pod phases back to the existing Worker/Job lifecycle and deletes the Job and ConfigMap during cleanup.

Before applying to a shared cluster, replace the `replace-me` values in `configmaps-secrets/platform-secret.yaml`. The manifests use ClusterIP DNS names (`backend`, `redis`, `minio`, and so on) and PVC-backed storage. Grafana dashboards and its Prometheus datasource are provisioned through generated ConfigMaps.

The static worker Job under `jobs/` is a reference template only; production Jobs are generated by the scheduler. See `docs/deployment.md` for kind/minikube image loading, port-forwarding, and failure testing.
